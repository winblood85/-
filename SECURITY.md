# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue** для уязвимостей.

Используйте приватный канал GitHub:
**Security → Report a vulnerability** (Private vulnerability reporting) в этом репозитории.

Постараюсь ответить в течение 7 дней.

## Поддерживаемые версии

Исправления безопасности выпускаются только для актуального состояния ветки по умолчанию.
